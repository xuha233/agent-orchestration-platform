# AOP Desktop

This directory contains the future desktop shell for AOP.

Current direction:

- shell: Tauri
- frontend: React + TypeScript
- backend bridge: `aop.app_runtime`

This is currently a scaffold only. The first implementation target is:

- view projects
- view workflow artifacts
- run `aop run`
- configure providers

The Streamlit dashboard remains the compatibility/debug UI during migration.
